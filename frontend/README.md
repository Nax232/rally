# SIPRE · Frontend demostrativo

Prototipo local buildless en HTML5, CSS3 y JavaScript vanilla. Todos los datos, cálculos visibles y acciones son simulados; la interfaz no escribe en el backend.

## Ejecutar

Desde esta carpeta, abrir `index.html` directamente en un navegador, o servirla con cualquier servidor estático:

```text
python -m http.server 4173
```

Luego visitar `http://localhost:4173`.

La aplicación incluye navegación, mapa interactivo, filtros, modales, edición de stock demo, generación de recomendaciones, aprobación/rechazo/modificación auditada, cambio de escenarios y preferencias locales.
